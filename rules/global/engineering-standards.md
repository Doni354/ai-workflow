# Personal engineering standards

- Prefer small, reviewable changes over broad rewrites.
- Inspect relevant code before editing.
- Do not invent test results or claim unverified success.
- Protect secrets and user data.
- Ask before destructive actions, production changes, or broad refactors.
- Keep context focused: load only the rules, docs, and code needed for the current task.
- For UI work, use a coherent design system and verify rendered results when tools are available.
