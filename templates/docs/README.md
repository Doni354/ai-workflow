# Documentation templates

Copy these templates only when appropriate. They are intentionally blank and must be populated from verified project evidence.

Recommended onboarding order:
1. `PROJECT_CONTEXT.md`
2. `architecture.md`
3. `design-system.md` if the project has a UI
4. `data-model.md` and `api-contracts.md` when relevant
5. A focused file under `docs/plans/` for each non-trivial task
